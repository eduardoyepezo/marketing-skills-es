# Referencia Cruzada de Ideas — 139 Ideas de Marketing Mapeadas a AARRR

La skill `marketing-ideas` cataloga 139 tácticas de marketing probadas. Este documento es el mapeo fuente de verdad: cada idea asignada a una etapa AARRR primaria, con notas sobre cuándo típicamente está activa y qué restricciones de categoría aplican.

La Sección 12 del plan ("Banco táctico de ideas") usa este mapeo como base, luego agrega filtros específicos del cliente: las reglas de voz de marca pueden omitir algunas ideas; la etapa de financiamiento puede cambiar el estado de Q; la categoría del cliente puede descartar otras.

## Cómo leer este documento

- **139 ideas únicas, 144 entradas.** Cinco ideas cruzan múltiples etapas AARRR y aparecen bajo cada etapa a la que sirven (#79 Referidos de Acceso Anticipado, #86 Ofertas de por Vida, #91 Upsells In-App, #114 Marketing Moneyball, #117 Competencias de Producto). Cada fila duplicada lleva una nota de cruce.
- **"Entradas" cuenta filas; los IDs de idea son únicos.** Los conteos de encabezado de sección reflejan filas en este documento, no ideas únicas de `marketing-ideas`.
- **Los números corresponden exactamente al orden de la skill `marketing-ideas`.** Si `marketing-ideas` reordena o expande, actualiza este documento.

## Cómo aplicar esto a un cliente específico

Para la Sección 12 del plan:

### Paso 1 — Filtrar por ajuste de categoría

Para cada idea, pregunta:
- ¿Esta idea aplica a la categoría del cliente? (p. ej., #16 Importadores solo para SaaS; #19 Extensiones de Chrome solo si es relevante para navegador; #136 DevRel solo para dev tools)
- Omite ideas que no aplican, con una nota

### Paso 2 — Filtrar por voz de marca

Para cada idea, pregunta:
- ¿Esta idea entra en conflicto con la voz de marca del cliente?
- Conflictos comunes:
  - **Ofertas de por Vida (#86)** — entra en conflicto con posicionamiento premium
  - **Sorteos en Twitter (#83)** — a menudo fuera de marca para voces serias / clínicas / de lujo
  - **Marketing con Humor (#122)** — fuera de marca para voces serias / clínicas
  - **Marketing de Cameo (#118)** — fuera de marca para la mayoría de las voces
  - **Marketing de Reality TV (#112)** — fuera de marca para la mayoría de las voces

Si hay conflicto, colócala en la lista de Omitidos con justificación explícita.

### Paso 3 — Fijar el estado de timing

Para las ideas que pasan los filtros, fija el estado:
- **Ahora (Q1)** — ya está en el plan a 90 días O puede correr en paralelo sin nueva capacidad
- **Q2** — post-corrección-de-base, post-fundación; capa del segundo trimestre
- **Q3+** — post-cierre-de-seed, post-GA; movidas de expansión
- **Q4+** — juego largo / gran inversión

Usa la columna "Etapa típica disponible" como el default. Cámbiala antes si el cliente tiene capacidad inusual (p. ej., un founder celebridad cambia Charlas en Conferencias #70 de "Ahora" a "Ahora y de alto apalancamiento").

### Paso 4 — Escribir la nota específica del cliente

Cada idea "Ahora / Q2 / Q3+" recibe una nota de una línea específica del cliente. Ejemplos:
- Para la idea #11 Páginas de Comparación con Competidores: "Quietude vs. Calm / Headspace / Brain.fm / Endel / Wavepaths — SERPs de alta intención"
- Para la idea #133 Marketing a Inversionistas: "El levantamiento de seed de Alex — aprovechar el backchannel de angels para PR + intros"
- Para la idea #15 Ingeniería como Marketing: "Guía de interpretación de HRV; autoevaluación del sistema nervioso; directorio de buscador de baño de sonido"

### Paso 5 — Sumar el banco

Después de las cinco tablas AARRR + la lista de omitidos:

```markdown
### Resumen del banco de ideas

- {conteo de Adquisición} ideas aplicables a Adquisición (la etapa dominante en la etapa actual de {cliente})
- {conteo de Activación} a Activación, {conteo de Retención} a Retención
- {conteo de Referidos} a Referidos
- {conteo de Ingresos} a Ingresos
- {conteo transversal} transversales
- {conteo de omitidas} ideas omitidas por ajuste de marca / negocio

**Lo que esto demuestra:** el plan es aproximadamente X% de la superficie táctica disponible, no el 100%. {apropiado o no para la etapa} — a medida que se desbloquea capacidad a través de Q2 → Q3 → Series A, la referencia cruzada se convierte en el inventario para escalar la actividad sin perder coherencia estratégica.
```

## Cómo mantener este documento

Si `marketing-ideas` agrega nuevas ideas (es una skill viva — las 139 pueden convertirse en 145 o 160 con el tiempo):
1. Lee `skills/marketing-ideas/references/ideas-by-category.md` en el repo `marketingskills`
2. Asigna cada idea nueva a una etapa AARRR primaria usando las reglas de arriba
3. Agrégala a las tablas de este documento
4. Actualiza la referencia del conteo de ideas en SKILL.md
